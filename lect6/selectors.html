CSS Selectors - Complete Guide with Examples

1. Element/Type Selectors
Select elements by their HTML tag name
p { color: #333; }

This is a paragraph selected by element selector. All <p> tags will have this color.

This is another paragraph. The selector applies to all p elements on the page.

2. Class Selectors
Select elements by their class attribute (prefixed with .)
.intro { background-color: #cfe2ff; }
This div has the 'intro' class - it's highlighted with a blue background.
This div has the 'warning' class - it's styled differently.
This div has the 'success' class - it shows success styling.
3. ID Selectors
Select a specific element by its ID attribute (prefixed with #). IDs should be unique!
#main-header { background-color: #343a40; }
This div has ID 'main-header'. IDs are unique and target ONE element.
This div has ID 'featured'. Use IDs for unique page elements.
4. Universal Selector
Select ALL elements on the page (using *)
* { margin: 0; padding: 0; box-sizing: border-box; }

The universal selector targets every element. It's commonly used to reset default styles.

Every element on this page has been affected by the universal selector rules.

5. Attribute Selectors
Select elements based on their attributes

a) [attribute] - Has attribute

input[type="text"] { padding: 8px; border: 1px solid #ddd; }




b) [attribute*="value"] - Contains

a[href*="google"] { color: #1f6feb; font-weight: bold; }
Link containing 'google' in URL
Regular link (not styled)

c) [attribute^="value"] - Starts with

a[href^="https"] { text-decoration: underline; }
Link starting with https (underlined)
Link with http (not underlined)
6. Pseudo-Class Selectors
Select elements in a specific state or position

a) :hover - When mouse is over element

a:hover { color: #ff6b6b; text-decoration: underline; }

Hover over this link to see the :hover effect

b) :first-child - First child element

li:first-child { font-weight: bold; color: #28a745; }
  • First item (styled with :first-child)
  • Second item
  • Third item

c) :last-child - Last child element

li:last-child { font-style: italic; color: #6c757d; }
  • First item
  • Second item
  • Third item (styled with :last-child)

d) :nth-child(n) - Specific child position

li:nth-child(2) { background-color: #fff3cd; }
  • First item
  • Second item (styled with :nth-child(2))
  • Third item

e) :focus - Element has focus

input:focus { outline: 2px solid #007bff; }

7. Pseudo-Element Selectors
Style specific parts of an element

a) ::before - Add content before element

.quote::before { content: "💡 "; }

This is a quote. The bulb emoji is added with ::before

b) ::after - Add content after element

.quote::after { content: " - Important!"; }

Another quote with added text

c) ::first-letter - Style first letter

.intro-text::first-letter { font-size: 2em; font-weight: bold; }

This paragraph has a large first letter styled with ::first-letter

d) ::first-line - Style first line

.intro-text::first-line { font-weight: bold; }

This is the first line which will be bold. This is the second line which won't be bold. The ::first-line selector only styles the first line.

8. Combinator Selectors
Select elements based on their relationship to other elements

a) Child Combinator (>)

.parent > .child { margin-left: 20px; }
Parent element
Direct child (styled with >)

b) Descendant Combinator (space)

.ancestor .descendant { color: #6f42c1; }
Ancestor element

Nested descendant (styled - any level deep)

c) Adjacent Sibling Combinator (+)

.sibling + .next-sibling { background-color: #d1ecf1; }

First sibling paragraph

Second paragraph (directly after first - styled with +)

Third paragraph (not styled)

d) General Sibling Combinator (~)

.sibling ~ .all-siblings { border-top: 1px solid #dee2e6; }

First sibling paragraph

Second paragraph (styled with ~)

Third paragraph (also styled with ~)

9. Grouping Selectors
Apply same styles to multiple selectors (separated by commas)
.section, .article, .post { border: 1px solid #ddd; }
This is a section (styled)
This is an article (styled)
This is a post (styled)
10. Multiple Selectors (Grouping)
Apply the same style to multiple heading levels
h2, h3 { color: #007bff; margin-top: 20px; }
